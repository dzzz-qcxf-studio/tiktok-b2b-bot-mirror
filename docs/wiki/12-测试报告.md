### 覆盖率分析

**🟢 优秀（>80%）**: 数据模型、平台抽象、事件总线、扩展注册器、过滤器
- 单元测试覆盖充分

**🟡 中等（50-80%）**: 存储层、LLM、Settings、Pipeline 编排、Keyword Collector
- 核心路径已覆盖，部分边界未测试

**🔴 偏低（<50%）**: Browser Client、Auth Service、Channels、Recommendation/Competitor Collectors
- 这些模块依赖 Playwright 真实浏览器运行（需 headless chromium）
- 测试需要 mock 整个 Playwright API 才能覆盖
- 当前通过间接验证（Pipeline 测试覆盖了它们的使用路径）

### Pipeline 测试稍慢原因

`test_pipeline_collect_stage` 包含：
1. Mock VectorStore 实例化（chromadb embedding 模型加载耗时长）
2. 临时 SQLite 创建
3. Pipeline 调用链

## 修复的真实问题

测试发现并修复的关键问题：

| 问题 | 位置 | 解决方案 |
|------|------|----------|
| Python 3.10 `str \| None` 语法错误 | `platforms.py:22` | 改用 `Union[str, "PlatformType"]` |
| `tiktok_accounts` 单一 unique 约束 | `models/entities.py` | 改为 `(platform, username)` 复合约束 |
| AuthService 单例缓存 DB 引用 | `tests/test_platforms_auth.py` | fixture 重置单例 |
| ORM 对象 DetachedInstanceError | 多处测试 | 在 session 内取值 |
