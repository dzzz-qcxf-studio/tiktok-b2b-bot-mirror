## 依赖方向

```
UI (Vue) ──http──▶ API (FastAPI) ──call──▶ Core ──call──▶ Plugin
CLI (Click) ──call──▶ Core ──call──▶ Plugin
Skills (Hermes) ──CLI──▶ CLI ──call──▶ Core
```

**核心原则：**
- UI 不直接调 Core
- CLI 是唯一的程序入口
- API 是 CLI 的 HTTP 包装
- Skills 是 CLI 的 Hermes 包装

## 目录结构

```text
tiktok-bot-software/
├── tiktok_bot_core/              # 业务核心（CLI/API 共享）
│   ├── models/entities.py        # 9 个 SQLAlchemy ORM 实体
│   ├── storage/
│   │   ├── database.py           # SQLite 引擎 + session 管理
│   │   ├── sqlite_store.py       # CRUD 仓库
│   │   └── vector_store.py       # ChromaDB 向量存储
│   ├── events/bus.py             # 异步事件总线
│   ├── extensions/registry.py    # 插件注册器
│   ├── settings.py               # Pydantic Settings
│   ├── llm/client.py             # DeepSeek 客户端
│   ├── browser/client.py         # Playwright 浏览器封装
│   ├── plugins/                  # 三类插件实现
│   │   ├── collectors/           # 搜集 (keyword/recommendation/competitor)
│   │   ├── channels/             # 触达渠道 (comment/dm)
│   │   └── filters/              # 筛选 (llm/composite)
│   └── services/pipeline.py      # 6环节 PipelineService
│
├── tiktok_bot_api/               # FastAPI REST 接口（30+ 端点）
├── tiktok_bot_console/           # CLI (Click) + UI (Vue3, 11 个页面)
├── skills/                       # Hermes Skills 薄包装（4 个 Skill）
├── tests/
│   ├── test_core.py              # ✅ 10 passed
│   ├── test_plugins.py           # ✅ 8 passed
│   ├── test_pipeline.py          # ✅ 5 passed
│   └── test_platforms_auth.py    # ✅ 13 passed（双平台 + 真实登录）
├── data/                         # SQLite + ChromaDB 数据
├── docs/wiki/                    # 开发者 WIKI
├── pyproject.toml
└── .gitignore
```

## 借鉴 ChopperBot

| ChopperBot (Java) | 我们的 Python 等价 |
| --- | --- |
| 多模块 Maven 聚合 (pom.xml) | Python 三层包 (core/api/console) |
| META-INF 插件声明 | `extensions/registry.py` 注册表 |
| PluginInitMachine | `plugins/plugincore.py` 自动注册 |
| Spring Event | `events/bus.py` 异步事件总线 |
| Spring DI | Python 模块全局单例 |
| MyBatis Mapper | SQLAlchemy ORM |
| Vuetify 3 + ApexCharts | Element Plus + ECharts |
