## 环境搭建

```bash
cd tiktok-bot-software

# 安装依赖 (国内镜像)
pip install sqlalchemy chromadb openai pydantic pydantic-settings \
  python-dotenv python-telegram-bot matplotlib click fastapi uvicorn \
  pytest pytest-asyncio rich -i https://pypi.tuna.tsinghua.edu.cn/simple

# Playwright 浏览器
playwright install chromium

# 初始化数据库
python -c "from tiktok_bot_core.storage.database import init_db; init_db()"

# 配置 .env
cp .env.example .env
# 编辑: DEEPSEEK_API_KEY=sk-xxx、JWT_SECRET=<随机长字符串>

# 启动 API（必须加载 .env，且保持单 worker）
python -m uvicorn tiktok_bot_api.main:app --env-file .env --reload --port 8000

# 推荐：项目根目录一次启动前后端；重复执行不会重复启动健康服务
powershell -ExecutionPolicy Bypass -File .\start-services.ps1

# 运行测试
python -X utf8 -m pytest tests/ -v
```

`start-services.ps1` 会在后台隐藏窗口中启动缺失的服务，并将日志写入 Git 忽略的
`data/logs/`。后端默认按 `8000, 8400–8409` 的确定顺序选择：先识别已经运行的本项目 API，
再用 `TcpListener` 做真实 loopback bind 探测，因此 Windows excluded/reserved port 即使没有
LISTEN 进程也会被跳过。需要固定端口时使用：

```powershell
powershell -ExecutionPolicy Bypass -File .\start-services.ps1 -BackendPort 8407
```

前端固定在 `http://127.0.0.1:5173`，启动时通过 `VITE_API_BASE` 继承所选 API 地址并使用
`--strictPort`。Vite 只读端点 `/__tiktok-bot-runtime` 返回固定 `appId` 与当前 `apiBase`；脚本
只复用 marker、API 身份和 health 三者一致的组合。5173 上的陌生页面、错误 API 绑定或返回
HTML 的 SPA fallback 都会 fail-fast，不能误报健康。重复启动优先复用现有配对。

## 添加新 Collector

```python
# 1. 创建文件: tiktok_bot_core/plugins/collectors/my_collector.py
from tiktok_bot_core.extensions.registry import CollectorPlugin

class MyCollector(CollectorPlugin):
    name = "my_source"

    async def collect(self, config: dict) -> list[dict]:
        # 自定义搜集逻辑
        return [{"tiktok_id": "user1", "username": "user1", ...}]

# 2. 注册
from tiktok_bot_core.extensions.registry import register
register().register_collector(MyCollector())
```

## 添加新 Channel

```python
# tiktok_bot_core/plugins/channels/follow_channel.py
class FollowChannel(ChannelPlugin):
    name = "follow"
    channel_type = "follow"

    async def execute(self, target, content, config) -> bool:
        browser = await get_browser()
        await browser.navigate(f"https://www.tiktok.com/@{target}")
        await browser.click('[data-e2e="follow-btn"]')
        return True
```

## 约定

1. **不硬编码** — API key、路径、阈值通过 `Settings` 读取
2. **Plugin 不解耦业务** — 只做原子操作
3. **错误不传播** — 阶段独立 try/catch
4. **状态可追溯** — 所有变更写 `updated_at`
5. **测试不调真实 API** — Mock 外部依赖

## 本地 API 安全与运行边界

- LLM 管理 API 必须携带 JWT 或 `X-API-Key`；密钥仅保存在 Git 忽略的项目 `.env`
- 本地 UI 默认来源为 `http://localhost:5173`；额外来源用 `CORS_ALLOWED_ORIGINS` 逗号分隔
- `JWT_SECRET` 必须稳定；推荐通过 `--env-file .env` 加载全部配置。若启动器漏传该参数，
  认证模块仍会从项目根目录 `.env` 读取 JWT 密钥，避免重启使既有登录 token 失效
- API 只能使用一个 worker；生命周期锁文件默认为 `data/api-worker.lock`
- Secret 相关测试必须 monkeypatch 到 `tmp_path/.env`；禁止读取或改写项目真实 `.env`
