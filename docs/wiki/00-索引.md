# TikTok B2B Bot — 开发者 WIKI 索引

> 版本: 0.3.0 | 最后更新: 2026-07-19

## 变更摘要（v0.3.0）

- ✨ **新增 UI 页面**：Leads（Lead 发现）、UserDetail（用户详情）、Pipeline、ConfigAccounts、ConfigLlm、ConfigPipeline、Login、NotFound
- ✨ **API 扩展**：30+ 端点（新增 pipeline/overview、users/detail、reports/overview、leads/search、llm/providers 等）
- ✨ **手动添加用户**：`POST /api/users` 端点 + 前端表单
- ✨ **数据库补全**：`accounts` 表（系统登录）+ `tiktok_accounts` 表完整文档化
- ✨ **抖音登录修复**：实测验证选择器（弹窗自动弹出 + localStorage 登录检测）
- ✨ **前端交互闭环**：所有按钮绑定真实 API（删除/检测/退出/批量检测/导入 Cookie/导出日报/测试连接/切换 Provider）

## 变更摘要（v0.2.0）

- ✨ **新增双平台支持**（TikTok + 抖音）— 通过 `Platform` 抽象自动切换 URL/选择器
- ✨ **新增真实登录**（Playwright QR Code 流程 + Cookie 持久化）— 替代原 fake 存储
- ✨ **数据库升级**：`users` 表加 `platform` 列；`tiktok_accounts` 表加 `platform` 列和 `status` 字段
- ⚠️ **API 变更**：原 `/api/tiktok/accounts` 重构为 `/api/accounts`，新增 login-qrcode 等端点
