# 07 — 数据库设计

> 关联: [索引](00-索引.md) | [Core层](03-Core层.md)

## SQLite ER 关系

```text
users (1) ──────< strategies (N)    # 一个用户多条策略
users (1) ──────< messages (N)      # 一个用户多次触达
messages (1) ──< replies (N)        # 一个触达多条回复
daily_reports                        # 独立日统计表
experience_rules                     # 独立经验表
config_records                       # 独立配置表
accounts                             # 系统登录账号（用户名密码）
tiktok_accounts                      # 社交平台账号（TikTok + 抖音，Cookie 持久化）
```

## 核心表结构

### users

| 列 | 类型 | 说明 |
| --- | --- | --- |
| id | PK | 主键 |
| platform | VARCHAR(20) | tiktok / douyin |
| tiktok_id | TEXT UNIQUE | 平台用户 ID（如 `tiktok:alice`） |
| username | TEXT | @用户名 |
| nickname | TEXT | 昵称 |
| bio | TEXT | 个人简介 |
| follower_count | INTEGER | 粉丝数 |
| following_count | INTEGER | 关注数 |
| like_count | INTEGER | 获赞数 |
| video_count | INTEGER | 视频数 |
| country | VARCHAR(50) | 国家/地区 |
| category | TEXT | buyer/distributor/manufacturer/competitor/unknown |
| status | TEXT | pending/qualified/rejected/contacted/replied |
| source | TEXT | keyword_search/recommendation/competitor/manual |
| source_keyword | TEXT | 来源关键词 |
| created_at | DATETIME | 创建时间 |
| updated_at | DATETIME | 更新时间 |

### strategies

| 列 | 类型 | 说明 |
| --- | --- | --- |
| id | PK | 主键 |
| user_id | FK→users.id | 所属用户 |
| persona | TEXT | 用户画像 |
| strategy_type | TEXT | soft_sell/hard_sell/partnership |
| comment_template | TEXT | 评论话术 |
| dm_template | TEXT | 私信话术 |
| action_plan | TEXT | 执行计划 |
| priority | INTEGER | 1-5 优先级 |
| created_at | DATETIME | 创建时间 |

### messages

| 列 | 类型 | 说明 |
| --- | --- | --- |
| id | PK | 主键 |
| user_id | FK→users.id | 目标用户 |
| message_type | TEXT | comment/dm |
| content | TEXT | 发送内容 |
| status | TEXT | pending/sent/failed/replied |
| sent_at | DATETIME | 发送时间 |
| error_msg | TEXT | 失败原因 |
| created_at | DATETIME | 创建时间 |

### daily_reports

| 列 | 类型 | 说明 |
| --- | --- | --- |
| id | PK | 主键 |
| report_date | DATE UNIQUE | 日报日期 |
| new_users_found | INTEGER | 新增用户 |
| users_qualified | INTEGER | 合格用户 |
| users_rejected | INTEGER | 淘汰用户 |
| comments_sent | INTEGER | 评论数 |
| dms_sent | INTEGER | 私信数 |
| replies_received | INTEGER | 回复数 |
| reply_rate | REAL | 回复率 |
| positive_replies | INTEGER | 正面回复数 |
| business_leads | INTEGER | 商业线索数 |
| notes | TEXT | 备注 |
| created_at | DATETIME | 创建时间 |

### accounts（系统登录账号）

| 列 | 类型 | 说明 |
| --- | --- | --- |
| id | PK | 主键 |
| username | TEXT UNIQUE | 登录用户名 |
| password_hash | TEXT | SHA256 加盐密码哈希 |
| api_key_hash | TEXT | API Key 哈希 |
| created_at | DATETIME | 创建时间 |

### tiktok_accounts（社交平台账号）

| 列 | 类型 | 说明 |
| --- | --- | --- |
| id | PK | 主键 |
| platform | VARCHAR(20) | tiktok / douyin |
| username | TEXT | 用户自起标识（如 marketing_01） |
| nickname | TEXT | 平台昵称 |
| cookies_json | TEXT | Playwright cookies 序列化 JSON |
| status | TEXT | pending / logged_in / expired |
| login_method | TEXT | qrcode / phone / password |
| qrcode_token | TEXT | 当前登录会话 token |
| last_login_at | DATETIME | 上次登录时间 |
| follower_count | INTEGER | 账号粉丝数 |
| created_at | DATETIME | 创建时间 |
| updated_at | DATETIME | 更新时间 |

唯一约束：`(platform, username)` — 同名账号在不同平台可独立存在

## ChromaDB 集合

| 集合 | 预估量 | 用途 |
| --- | --- | --- |
| `user_profiles` | ~10K | bio→embedding，相似用户搜索 |
| `message_strategies` | ~K | 话术→embedding，高效策略检索 |
| `experience_memory` | ~100 | 经验文本→embedding，历史回顾 |

三个集合均使用 `cosine` 距离度量。
