# 01 — 项目概述

> 关联: [索引](00-索引.md) | [架构设计](02-架构设计.md)

## 一句话描述

面向 TikTok 平台的 B2B 外贸业务拓展自动化系统。运行在 **Hermes Agent** 框架下，提供三层接口：
- **Web UI** — 人类操作的可视化管理面板
- **CLI** — AI Agent 可调用的命令行工具
- **REST API** — 远程/程序化访问的 HTTP 接口

## 核心目标

| 目标 | 说明 |
| --- | --- |
| 自动化获客 | 6 环节流水线：搜集 → 筛选 → 策略 → 触达 → 汇总 → 迭代 |
| 可视化监控 | Vue 3 管理面板：Dashboard + 用户列表 + 策略/执行/报告 |
| AI 可操作 | CLI 命令行工具 + Hermes Skills 薄包装 |
| 插件化扩展 | Collector/Channel/Filter 三类插件可替换 |
| 长期运行 | SQLite（人读）+ ChromaDB（AI 语义）双存储 |

```text
┌──────────┐  ┌──────────┐  ┌──────────┐  ┌──────────┐  ┌──────────┐  ┌──────────┐

│ 用户搜集 │  │ 用户筛选 │  │ 策略制定 │  │ 执行触达 │  │ 数据汇总 │  │ 闭环迭代 │
└──────────┘  └──────────┘  └──────────┘  └──────────┘  └──────────┘  └──────────┘
     │              │             │             │             │             │
   输出:          输出:         输出:         输出:         输出:         输出:
  用户清单      有效用户表    策略+计划    执行记录+回复  数据图表+追踪  优化规则

```

## 技术栈

| 层 | 技术 | 用途 |
| --- | --- | --- |
| Core 业务逻辑 | Python 3.11+ | 所有业务逻辑 |
| ORM | SQLAlchemy 2.0 | 数据库抽象 |
| 向量存储 | ChromaDB | 用户画像/话术/经验语义搜索 |
| 浏览器自动化 | Playwright | TikTok 操作（搜索/评论/私信） |
| LLM | DeepSeek (OpenAI 协议) | 用户筛选/策略生成/经验分析 |
| REST API | FastAPI + Uvicorn | 给 Web UI 提供数据 |
| CLI | Click + Rich | 给 AI Agent 提供命令行 |
| 前端 | Vue 3 + Element Plus | 管理面板 |
| 图表 | matplotlib / ECharts | 趋势图/分布图 |
| 通知 | python-telegram-bot | 日报推送 |
