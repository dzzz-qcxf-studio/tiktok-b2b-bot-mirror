# 10 — 账号管理（真实登录 + Cookie 持久化）

> 关联: [索引](00-索引.md) | [双平台支持](11-双平台支持.md) | [Core 层](03-Core层.md)
> 最后更新: 2026-06-09

## 设计目标

替代原本"存 cookies_json 字符串就算登录"的 fake 实现，提供：

1. **真实 QR 扫码登录** — 用 Playwright 打开登录页 → 截屏 QR → 等用户扫码 → 持久化真正 cookies
2. **Cookie 持久化** — 登录成功后 cookies 序列化保存到 SQLite，下次自动恢复
3. **会话有效性检测** — 定期通过访问受保护页面检测 cookie 是否还有效
4. **多账号管理** — 支持 1-3 个账号轮换使用，配合反封号策略

## 核心组件

```
services/auth_service.py
└── AuthService          # 登录生命周期管理
    ├── list_accounts()          # 列出账号
    ├── add_account()            # 仅添加元信息（还不登录）
    ├── start_qrcode_login()     # 启动 QR 登录流程
    ├── _qrcode_login_task()     # 后台任务：打开浏览器 → 等扫码 → 保存 cookies
    ├── check_login()            # 轮询登录状态
    ├── load_cookies_to_browser()  # 把已登录账号的 cookies 注入到浏览器
    └── check_session_valid()    # 检测 cookie 是否还有效
```

## 登录标记（识别已登录状态的 cookie 字段）

```python
LOGIN_MARKERS = {
    PlatformType.TIKTOK: ["sessionid", "ttwid", "msToken"],
    PlatformType.DOUYIN:  ["sessionid", "ttwid", "uid_tt", "LOGIN_STATUS"],
}
```

此外，抖音还检查 `localStorage.HasUserLogin == "1"` 作为辅助登录标识。

只要 `LOGIN_MARKERS` 中任一字段出现在 cookies 里，就视为已登录。

## 登录流程（API 调用链）

```
┌──────────┐                                  ┌──────────┐
│   UI     │  1. POST /api/accounts/login-qrcode  │   API    │
│ (Vue)    │─{platform:"tiktok", username:"m1"}──▶│ (FastAPI)│
│          │◀─{session_token:"abc123"}──────│          │
└────┬─────┘                                  └────┬─────┘
     │                                              │
     │ 2. GET /api/accounts/login-status?token=abc123 │ 启动 Playwright 后台任务：
     ▼                                              ▼
  拿到 status                                       │
  - waiting: 显示 qrcode_url                       打开 tiktok.com/login
  - success: 关闭弹窗，跳到账号页                  截屏二维码
                                                轮询 cookies 5 分钟
                                                发现 sessionid → 登录成功
                                                保存 cookies_json + status="logged_in"
```

## API 端点

| 端点 | 方法 | 说明 |
|------|------|------|
| `/api/accounts` | GET | 列出账号（可按平台过滤） |
| `/api/accounts` | POST | 添加账号元信息（还不登录） |
| `/api/accounts/{id}` | DELETE | 删除账号 |
| `/api/accounts/{id}/cookies` | PUT | 手动更新 cookies |
| `/api/accounts/login-qrcode` | POST | 启动 QR 扫码登录 |
| `/api/accounts/login-status` | GET | 查询登录状态（轮询） |
| `/api/accounts/qrcode/{token}` | GET | 下载二维码图片 |
| `/api/accounts/{id}/check-session` | POST | 检测 cookie 有效性 |

## 数据库表 `tiktok_accounts`

| 字段 | 类型 | 说明 |
|------|------|------|
| id | PK | |
| platform | str | tiktok / douyin |
| username | str unique | 用户自起（marketing_01 等） |
| nickname | str | 平台返回的昵称（可选） |
| cookies_json | text | Playwright cookies 序列化 JSON |
| status | str | pending / logged_in / expired / suspended / rate_limited |
| login_method | str | qrcode / phone / password |
| qrcode_token | str | 当前登录会话 token |
| last_login_at | datetime | 上次登录时间 |
| follower_count | int | 账号粉丝数（用于观察是否被限制） |

## 安全注意事项

1. **不在前端存 cookies** — 只存 session token，cookies 只在浏览器内
2. **登录 IP 检测** — TikTok 会做 IP 风控，常用账号在固定 IP 登录更安全
3. **频繁掉线检测** — 自动检测 status 从 logged_in → expired，触发重新登录
4. **多账号轮换** — 业务执行时从 `get_active_account(platform)` 取一个账号，轮换避免单账号过载

## 失败场景处理

| 场景 | 处理 |
|------|------|
| Playwright 未安装 | 启动时 RuntimeError 给出安装提示 |
| 浏览器版本不匹配 | 提示运行 `playwright install chromium` |
| 用户未扫码 | 5 分钟超时返回 status="timeout" |
| Cookie 过期 | 状态自动更新到 expired，下次采集前重新登录 |
| TikTok 风控页面 | 检测 URL 包含 login 字样 → 自动标 expired |
