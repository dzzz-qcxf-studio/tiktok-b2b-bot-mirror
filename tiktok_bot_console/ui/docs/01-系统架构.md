## 数据流

```
View ──> api/index.ts ──> USE_MOCK?
                          ├─ true  ──> mockApi (mock.ts)  返回 axios 形状 { data }
                          └─ false ──> realApi ──┬─ 200 → 返回
                                              └─ 失败 → mockApi 兜底
```

`withMockFallback` 包装器：dev 模式下后端不可达时自动 fallback 到 mock，保证演示不中断。
生产模式（`VITE_USE_MOCK=false`）下失败直接抛出，不静默。

## 模块边界

- **View 不直接 import mock**——只能通过 `import { ... } from '../api'`，这样切换 mock/real 时无需改动 View
- **mock.ts 不引用 Vue/组件**——纯数据 + 异步函数，便于后端真实接口对接时直接替换
- **i18n key 集中管理**——硬编码中文字符串全部走 `$t(...)`
- **设计 token 走 CSS 变量**——`--brand`/`--surface`/...，组件不直接写 oklch 颜色值
