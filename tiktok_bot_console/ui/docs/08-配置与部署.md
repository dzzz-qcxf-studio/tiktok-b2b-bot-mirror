# 08 · 配置与部署

最后更新：2026-08-09

## 环境要求

- Node.js ^22.18 || >=24.12（package.json `engines`）
- npm 11+（用国内镜像 `https://registry.npmmirror.com`）

## 安装依赖

```bash
cd tiktok-bot-software/tiktok_bot_console/ui
npm install --registry=https://registry.npmmirror.com
```

## 环境变量

复制 `.env.example`（如有）到 `.env.local`：

| 变量 | 必填 | 说明 |
|------|------|------|
| `VITE_USE_MOCK` | 否（默认 false） | `true` 时所有数据走 mock |
| `VITE_API_BASE` | 否（默认 `http://localhost:8000`） | 后端 baseURL |
| `VITE_ENABLE_DEVTOOLS` | 否（默认 false） | `true` 时显示 Vue DevTools；窄屏验收应保持关闭 |

```env
# 演示模式（无需后端）
VITE_USE_MOCK=true

# 接真实后端
VITE_API_BASE=http://your-backend:8000
VITE_USE_MOCK=false
VITE_ENABLE_DEVTOOLS=false
```

## 常用命令

```bash
npm run dev          # 启动 dev server（HMR，端口 5173）
npm run build        # 生产构建（含 type-check + build-only）
npm run preview      # 预览生产产物
npm run type-check   # 单独类型检查（vue-tsc）
npm run test         # 烟雾测试（scripts/smoke.mjs）
```

## 启动顺序

在项目根目录推荐执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\start-services.ps1
```

脚本只补启动不健康的服务，并等待前端和后端健康后返回；日志位于 `data/logs/`。也可以
手动先在 `:8000` 启动 FastAPI，再在本目录执行 `npm run dev`。最后访问
`http://localhost:5173` 并使用已注册的系统账号登录。

## 演示模式（推荐路径）

```bash
# 仅前端，零后端依赖
VITE_USE_MOCK=true npm run dev
```

启动后所有数据从 `src/api/mock.ts` 返回，可演示：
- Dashboard 30 天 Pipeline 效果图
- Pipeline 实时事件流（每 5s 自动刷新）
- Reports 30 天 Pipeline 输出图（堆叠柱 + 折线）
- 关键词云（EN / 中 切换）
- 用户列表、画像详情

## 部署

```bash
npm run build
# 产物在 dist/
# 部署到任意静态服务器（Nginx / CDN）
```

注意：`VITE_*` 变量在 build 时被内联到 bundle，部署后无法热改。
