## 共享组件

### `WordCloud.vue`（自研）

- 螺旋避让算法（阿基米德螺旋 + 碰撞检测）
- props: `items: {word, count}[]`, `minHeight: number`, `rotateChance: number`
- 输入数据由调用方传入；词云本身不做数据获取
- 自动按 count 分桶：`b`(大) / `c`(中) / `o`(小) / `n`(默认)
- 中英文字符宽度估算分开（CJK ~1.0 em/字，拉丁 ~0.55 em/字）
- ~18% 的词随机旋转 ±5°~±23°

## 关键视图详情

### Dashboard.vue
- 顶部 4 个 KPI（Hero + 3 个普通卡片）
- Pipeline 实时状态条（6 节点）
- **30 天 Pipeline 效果图**（合格用户柱 + 回复率折线，X 轴日期刻度，Y 轴自适应）
- Top 5 关键词转化 + 用户画像分布
- 实时事件流（每 5s 刷新）

### Pipeline.vue
- 顶部 Hermes Agent Cron 信息条（动态 cron 时间）
- 操作工具栏（手动触发 / 查看 cron 配置）
- 6 环节 Pipeline 进度卡（done/running/pending/failed 状态）
- 6 项运行统计（总耗时 / LLM 调用 / 浏览器操作 / 账号切换 / 评论 / 私信）
- **实时事件流**（每 5s 轮询，最近 60 条，黑色终端样式）
- 最近 7 天运行历史
- 本轮结果列表

### Reports.vue
- 4 KPI（带 sparkline）
- **30 天 Pipeline 输出图**（堆叠柱 评论+私信 + 折线 回复）
- 转化漏斗
- 最佳触达时段热力图
- **用户画像关键词云**（WordCloud 组件 + EN/中切换）
- 地区回复分布表
- 回复情感分布（环形图）

### Users.vue
- 6 状态 KPI 条
- 多维筛选 chips（状态 / 画像 / 来源）
- 用户表格（带分页）

### UserDetail.vue
- 用户画像 + 关键词 tags（EN/中切换）
- 触达策略卡（策略话术）
- 视频样本
- B2B 质量分（6 维度）
- 互动时间线
- 关键词 tags（EN/中切换）

### Login.vue
- 左：品牌宣传 + Pipeline 实时数据
- 右：登录表单 + API Key 登录
